# pcbforge reference layout pattern catalog

No patterns have been published yet.

LAYOUT agents must state that the catalog is empty and transcribe a pattern into
the project's own `patterns/` directory instead. A pattern is available for reuse
here only after it is listed below with its part match, fidelity, exact source
citation, and capture date. A project copy always wins over this catalog by id.

Fidelity is `exact` only when the offsets came from vendor design files or a
dimensioned drawing. A pattern transcribed from a datasheet figure by eye is
`sketch`: it is measured like any other, but `pcbforge apply-pattern` refuses it,
because the millimetres are the transcriber's rather than the vendor's.
